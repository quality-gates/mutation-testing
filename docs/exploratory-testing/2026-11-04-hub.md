## Go quick start

The goal was to install mutago and run the documented covered score gate on a passing Go project. The sample module defined `Add(a, b int) int { return a + b }` and asserted that `Add(2, 3)` equals 5. `go test ./...` passed. The documented mutation command killed both mutants and reported 100% for both scores. See [the ordinary run](2026-11-04-hub/go-ordinary.txt).

For the variation, the test called `Add` without checking its result. The suite still passed, but both mutants escaped and the gate exited 4. The source file's SHA-256 matched before and after the run. See [the weak-test run](2026-11-04-hub/go-weak-test.txt). This result supports the hub's claim that mutation testing can reveal a passing test with no effective assertion.

## Rust quick start

The goal was to run the documented coverage gate on a passing Rust library. The sample defined `pub fn add(a: i32, b: i32) -> i32 { a + b }` and asserted that `add(2, 3)` equals 5. `cargo test --locked` passed. The documented mutation command exited 3 because `cargo-llvm-cov` was not installed. A second fresh sample reproduced the failure. See [the ordinary run](2026-11-04-hub/rust-ordinary.txt) and [the replay](2026-11-04-hub/rust-replay.txt).

The variation omitted coverage and ran `mutarust --min-msi 75 .`. It killed one mutant, exited 0, and left the source file unchanged. See [the variation](2026-11-04-hub/rust-variation.txt). The diagnostic names `cargo-llvm-cov` and `llvm-tools-preview`, but the hub's Rust quick start does not identify those prerequisites. This is a documentation bug, filed as [issue #6](https://github.com/quality-gates/mutation-testing/issues/6). The complete coverage path was not tested because this machine lacks both rustup and the coverage tools.

## Limits and observations

The Haskell quick start was not executed. Neither `cabal` nor `ghc` was installed. The hub shows `cabal run mutaskell` without stating the required project context or a coverage data prerequisite. The linked mutaskell README describes `--tix` for covered MSI. This is an unresolved documentation observation, not a confirmed bug from this pass.

The Rust failure is an ordinary missing-prerequisite failure, not evidence that mutation itself is broken. The comparison without coverage passed. No product fixes are included in this report. No other candidates were confirmed.
